## 2026-11-25：Studio 首页产品化与推送

**决策与原因**：用户认为原首页过于技术文档化，初版重构仍像 demo，随后指出文字太多、图太少、字体字号和整体设计不足。确定以 Studio 为主要产品，默认亮色，深绿强调，以真实画面为主体、缩短重复文案并加入有节制的动效。

**已完成**：

- 首屏改为产品文案与真实 Studio 演示左右分栏；核心表达为“把想法做成视频，把细节改到满意”。
- 四支官方 HyperFrames 作品组成错落画廊，点击后播放；保留中文社区原创案例入口并区分归属。
- “描述想法、预览修改、导出作品”合并为真实界面切换，支持键盘操作；关闭作品播放层会停止、卸载媒体并恢复焦点。
- 公共导航调整为 Studio、作品、中文指南、更新与官方下载；首页主题独立于文档主题。
- 自托管 Noto Sans SC 可变字体；补充官方素材固定来源、修改范围、哈希与许可，保留无 JavaScript 和减少动态效果路径。

**本次实际验证**：`pnpm check` 通过；`pnpm test` 30 项通过；`pnpm build` 及 SEO/GEO 审计通过、0 错误；`pnpm test:indexing` 通过并恢复原配置；`pnpm test:e2e` 44 项通过、2 项按设备跳过。已查看桌面与手机截图，实际点播过官方 CDN 作品。原有原创影片源码未修改，本轮未重新渲染这些影片。

**提交与交付**：提交 `9f4106884ea37d4947bc2d107bc69e9b1fa6e98c`，分支 `feat/studio-homepage-redesign`，已推送并创建 [PR #10](https://github.com/xiaoyingjiang-studio/hyperframes-cn/pull/10)。直接推送 main 被分支保护拒绝，后续按独立分支与 PR 流程执行。创建后观察到 Checks 排队、Preview 等待；该观察不代表当前状态，也不代表完成合并或部署。

**边界与下一步**：官方录屏和截图不是本站登录 Studio 的实操记录；等待加速不能作为耗时承诺。后续先读取 PR 与工作流现状，维护者审核合并后再记录生产部署与线上回归结果；已有本地测试不能替代线上验收。
