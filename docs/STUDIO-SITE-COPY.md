# 小影匠工作室官网文案与交互规格

2026-11-28 · 公开文案用原创作品和创作者的实际需求讲合作，以旁白、图解、动画和录屏说明适合的作品形式。真实服务、联系渠道、样片授权与履约能力决定对外承诺。研究、试点与上线验收详见 [官网改版策划](STUDIO-STRATEGY.md)。

## 首页 `/`

页面标题为“小影匠工作室｜原创内容出海与海外运营”。可见摘要与搜索描述共用 `studio-home` 在 `content/discovery.json` 中的回答。导航有「改编示例」「合作方式」「出海手册」，品牌字标回到首页。

### 首屏

> # 你专心创作，我们负责海外运营。
>
> 从一条已有的原创作品开始。小影匠负责改编、剪辑、发布和复盘，帮你判断哪个海外方向值得继续。
>
> **带一条作品聊出海**　　看内容怎么改编

主按钮进入 `#contact`，次按钮跳到 `#adaptation`。首屏用麦克风、数位屏和手绘分镜表现制作过程。替代文字描述画面，制作来源记在 [品牌资产说明](../assets/brand/README.md)。桌面版文字与画面并排。手机版依次排标题、说明、主按钮和图片。微信号由 `PUBLIC_STUDIO_WECHAT_ID` 配置，明确授权公开后显示可复制的微信号。另可配置 `PUBLIC_STUDIO_CONTACT_URL` 作为公开 HTTPS 页面或邮箱入口。两者均空时显示准备清单与复制合作模板。

### 用改编示例证明判断力 `#adaptation`

> ## 同一条作品，给新观众一个好开头。
>
> 如果英语观众第一次刷到你的复利解说，什么会让他们想看下去？我们会保留原来的解释，用一个问题和一组数字带他们入题。

改编示例紧接首屏，用工作室自制的静态分镜对照「一张图看懂什么是复利」和「What if your interest earned interest?」。说明中文原版适合已经在了解这个术语的观众，改编版用 100、110、121 的数字示意适配第一次刷到作品的人。示例接到手册的完整拆解。以后补充真实试点时，用获得公开授权的片段说明确实发生的调整。

- **开头给结果。** 把作品完成、意外发生或有用结论提前，让第一次看到你的人知道为什么要继续看。
- **一条只讲一件事。** 从打招呼、读弹幕等直播情境中找到可以独立观看的过程，用一句话补足必须的前因。
- **保留你的声音。** 原声保留，字幕解释关键术语和方言。向目标受众测试是否看懂，再调整剪辑和译法。

画面旁标明「工作室自制演示」或实际授权身份、适配的受众假设、素材来源和改动时间。真实试点可以附账号链接、统计窗口和制作方实际参与范围。若还没有可公开素材，首屏用真实工作场景，先展示有标注的改编工作样张。

### 说清楚怎么合作

> ## 先试一轮，再决定要不要继续。
>
> **你提供作品。** 发一条代表作。方向和首版由你确认，之后按自己的节奏继续创作。
>
> **我们负责试运营。** 先约定给谁看、在哪发、试多久。小影匠按约定完成脚本改编、剪辑、字幕或配音和发布。
>
> **一起决定下一步。** 试完一起看成片、发布记录和观众反馈，再决定继续做、换个方向，还是先暂停。

「试完能看到什么」用三行展示复盘内容，分别讲改了什么、观众怎么看和下一条怎么做。反馈不足时写明限制。试运营的范围、时长及具体合作条款按作品确认。

### 让合作双方都知道边界

> ## 合作前，先说清楚。
>
> 账号由谁管理，素材允许用在哪里，发布前哪些内容需要你确认，产生收益后如何结算，停止合作怎么交接。开始前，我们逐项确认，再把它写进合作约定。

首页用可展开问答呈现。账号控制、数据可见性及退出交接在实际执行政策确定后，再成为官网的具体承诺。

### 让合适的创作者认出自己的作品 `#readiness`

用「已经在做自己的栏目？」说明持续原创、可授权的代表作和适合的作品形式。邀请已经发过海外版的创作者带那条作品来聊。链接到出海手册的完整作品自查。

### 首页最后的行动

> ## 发一条你的代表作。
>
> 我们先看这条作品哪里值得保留、适合给谁看，以及第一版可以怎么改。

开场只需要一条可访问的代表作链接，创作者也可以补充想尝试的方向。未配置联系入口时，提供合作模板。浏览器关闭 JavaScript 时，模板可手动复制。页脚保留工作室标识与原创文字许可入口，手册通过主导航、改编示例和作品自查接入。[创作者出海手册策划](STUDIO-EDITORIAL.md)

## 合作页 `/cooperate/`

标题建议为「主播出海运营怎么合作」。开头直接说明面向稳定创作、有原创内容和真实海外目标的主播及授权代表。接着按「你提供什么」「我们接手什么」「试完看什么」三列展示约定范围。

建议首发五个可扫描的常见问题，并按已确认政策具体回答。

| 问题 | 文案要说清的事 |
| --- | --- |
| 一定要会外语、去海外重新开播吗？ | 中文内容可先看适合的地区和形式。录播切片与实时海外开播分别评估，实时直播取决于语言、时区及平台资格。 |
| 我只有国内素材，可以先看一条吗？ | 可以从公开作品初评，进入制作前再确认素材、背景音乐和联动人员的授权。 |
| 账号、成片和数据归谁？ | 写明工作室的实际执行政策与合作例外，先给账号权限、原始素材、成片许可与数据查看四项明确边界。 |
| 要付多少钱、怎么分成？ | 简评费用、试点范围及计费是否公开由团队确定。长期合作先确认计价和结算规则，避免承诺未确认的价格、收益和分成比例。 |
| 要是方向不合适，可以停吗？ | 说明试点时限及适用的协议、权限退出、素材和数据交接方法。把限制条件放在同一段。 |

页底固定主动作「带一条作品聊出海」。展示模板时标记为样张，真实条款以实际可履行范围为依据。

## 公开自查 `/creators/readiness/`

标题建议为「主播出海前，先用五个问题看自己准备到哪了」。手机上用普通列表就能读完，填不填都能看到行动建议。

1. 你能挑出一条能代表自己的作品吗？
2. 这条作品的画面、音乐、参与者和合作合同允许用于这次试点吗？
3. 一个没进过你直播间的人，能说出这条内容最有意思的地方吗？
4. 如果找到一个适合的栏目，你能持续提供类似的原始素材吗？
5. 接下来几周，是否能留出时间确认方向与样片？

建议结果文案分三种情形。作品和授权可确认时，给「带一条作品聊出海」。已有作品、授权存疑时，给应先核对的音乐、联合出镜及已有合同清单。还没有明确看点或稳定素材时，引导到直播改编指南，用一条现有片段做一次自评。清单可直接分享，完整结果对访客可见。

## 作品申请 `/apply/`

> # 把一条作品发给我们。
>
> 可以是公开直播回放、短视频或主页里的一条代表作。我们会先看这条内容哪里值得试、要先解决什么，再通过你留下的方式回复。

| 字段 | 是否必填 | 内容、示例与行为 |
| --- | --- | --- |
| 代表作链接 | 是 | 一条可访问的公开链接。粘贴分享文本时提取明确的 HTTPS 地址，模糊或多链接时引导保留一个。暂时无法提供公开链接可走团队有效联系入口。 |
| 平时做什么内容 | 是 | 选择才艺/技能、知识/故事、聊天/娱乐、游戏、其他。选择“其他”仍可提交。 |
| 怎么联系你 | 是 | 微信或邮箱二选一，只填被选渠道。占位词写清需填写可被搜索到的微信号或有效邮箱。 |
| 你最想先试什么 | 否 | 短视频分发、已有账号的内容优化、海外直播可行性、还没想好。可加一句补充，提示仅写合作所需信息。 |
| 已阅读信息处理说明 | 是 | 紧邻提交按钮，链接到可访问的隐私说明，写明收到后用于本次合作沟通。后续营销按独立自愿选择处理。 |

表单按钮用「提交作品」。成功文案为“作品已收到。我们会通过你选择的方式联系你。”应在确认收件后显示，预计时效只有团队能履约才添入。错误留在本页、保留现有输入并可重试，手机键盘及屏幕阅读器能定位错误。若没有可用表单服务，首发使用团队可处理的真实单一联系入口，清楚提示发送“作品链接、内容类型、想先试的方向”；复制或打开联系入口之后显示实际操作结果。

工作室记录渠道、落地页和不含联系方式的随机提交 ID，联系信息和作品链接只进限定访问的业务收件处。服务端使用体积和频率限制、重复提交保护及失败可追踪的接收记录，测试去重与微信或邮件等实际采用的回复路径。上线前写清收集主体、目的、接收方、保留期、删除方式和联系渠道，按必要范围收集个人信息。分析系统只收事件名和允许枚举的渠道字段，表单内容及申请人链接不进入埋点和分享地址。[全国人大常委会个人信息保护法公报](https://wb.flk.npc.gov.cn/flfg/PDF/f67af9f12e1b4c83a998cf5a876ce0e4.pdf)

后端只保存访客提交的公开地址供工作室查看；如以后需要自动获取外部元信息，需单独设计域名约束及服务器请求防护。确认页可以引导回出海指南，避免把重复操作写成新的申请。

## 工作室接待模板

首版建议由一名负责人检查收件，按“已收到 → 待核对 → 已给简评 → 已沟通 → 试点中 → 结束或继续”记录。有回复能力时可参考下面的语气，把方括号替换为实际观察。素材用于更深制作前取得对应授权。

> 我们看了你发的这条作品。我会先试的是【可独立成立的看点】，因为第一次看到你的观众能从【具体画面／台词】进入。眼下先确认【版权／语境／持续供给等一个门槛】。如果能解决，建议先做【一项小范围改编】给【一类观众】看看。你愿意的话，我们约个时间把素材、权限和下一步范围聊清楚。

首版邀约模板供已建立联系或平台允许的主动沟通使用。

> 你好，我是小影匠工作室的【姓名】。看到你在【作品】里做的【一个具体细节】，我觉得没看过你直播的人也会好奇它是怎么做到的。我们在找有原创内容的主播一起试海外版本。如果你正在考虑出海，愿意发一条代表作的话，可以先聊聊哪个片段、哪类观众值得先试。
