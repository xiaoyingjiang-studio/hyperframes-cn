HyperFrames 开源框架与配套商业服务需要分别理解。评估成本时，从实际使用的工作流出发。

## 四类费用分别看

| 项目 | 需要了解 |
| --- | --- |
| 开源框架与 CLI | 官方仓库采用 Apache-2.0；本地运行仍消耗自己的电脑资源 |
| Studio 应用 | 官方提供免费方案，部分内置能力与额度受套餐限制 |
| 编码 Agent | 所选 Agent 或模型可能需要独立订阅、额度或 API 费用 |
| 素材和生成服务 | 配音、音乐、图片、视频、头像或云渲染可能有各自费用 |

## 做第一个视频如何控制依赖

先用文字、简单形状及自己有权使用的图片制作短片；把项目在本地预览并导出。明确每个步骤是否调用外部服务，再决定是否增加生成素材或云端流程。

不要仅凭一个“免费”标签判断完整视频的成本。涉及费用的操作，应查看相应服务当前的价格页与账户用量。

## 本站如何处理套餐信息

本站不在教程正文中固定展示容易过期的套餐金额。下载、套餐和额度以 [Studio 当前页面](https://hyperframes.studio/pricing)为准；相关功能若依赖付费方案，教程会指出条件。

开源代码的许可，也不自动决定素材、字体、音乐或第三方服务的使用权。具体项目应保留这些素材的出处和许可说明。可参考[本站许可与归属记录](/community/licenses/)。
