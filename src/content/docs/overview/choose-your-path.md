三条本地路径都围绕可编辑项目工作。根据你更习惯描述需求、与编码工具协作，还是直接控制文件来选择。

## 三条起点

| 路径 | 适合你，如果… | 需要准备 | 下一步 |
| --- | --- | --- | --- |
| Studio | 希望在同一个窗口里创作和预览 | 对应系统的应用、HeyGen 账号与可用服务 | [Studio 教程](/start/studio/) |
| AI Agent | 已经在使用 Codex、Claude Code 或 Cursor | 可用的 Agent、项目文件夹、相关 Skills 与本地依赖 | [Codex 教程](/start/codex/) |
| CLI | 希望明确控制项目结构、检查和导出 | Node.js、FFmpeg、浏览器渲染环境 | [CLI 教程](/start/cli/) |

## 如何判断第一条路径

第一次接触终端，优先考虑 Studio。已经在编辑代码，可以从熟悉的 Agent 开始；让它解释要运行的命令和项目位置。准备将视频制作纳入脚本或持续集成，则先理解 CLI 的完整工作循环。

使用 Agent 并不意味着所有依赖都自动可用。模型服务、素材生成、账号权限与本地渲染仍有各自条件。

## 在线聊天入口

官方也提供连接 AI 聊天服务的路径，适用工作区、产品状态及项目交付方式可能不同。需要免本地安装时，先查看本页官方来源中的 MCP 指南，确认自己账号是否支持。

## 能不能中途切换

本地项目可以继续交给其他兼容工具处理。切换前保存文件和媒体，并确认新工具读取相同项目目录；对线上托管项目，不预先假设一定能获得完整本地文件夹。第一次完成视频后，再逐步增加工具，通常更容易定位问题。
