好的提示词应让 Agent 理解目标观众、核心信息和完成标准。第一轮说明最重要的约束，后续根据实际画面逐步调整。

## 一条需求至少说清四件事

1. 给谁看，以及希望对方理解什么。
2. 使用什么材料：脚本、网址、图片、录屏或数据。
3. 视频长度、画面比例、语言和交付方式。
4. 哪些事实、品牌内容或素材必须保留。

## 可复用的中文起始提示词

> 使用 HyperFrames，为第一次了解本产品的用户制作一支 15 秒中文视频。素材以我提供的文档为准，不添加未经证实的效果和数字。16:9，分为问题、两项能力、行动提示。先给分镜与文案，确认后生成可编辑项目、预览并导出 MP4。任何收费服务调用前先说明。

## 用结果来反馈

“标题太小”可以进一步说明为：在手机宽度观看时读不清，让主标题减少到两行并增加字号；“节奏太慢”可以指出某个时间段和希望保留的信息。

一次反馈聚焦一个问题，修改后对比同一时间点。不要在没有看预览前连续增加很多抽象风格要求。

## 分清事实与创作表达

产品参数、用户数字、价格和引用需要来源；颜色、排版和镜头属于可探索的表达。缺失事实时，让 Agent 提问或省略，不让它补齐“看起来合理”的内容。

对品牌项目可保存一份明确的视觉规范，让后续作品沿用相同颜色、字体和运动规则。首次制作可以从[产品介绍案例](/showcase/product-intro/)开始。
