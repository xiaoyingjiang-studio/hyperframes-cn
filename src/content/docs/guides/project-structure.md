理解项目文件能帮助你判断 Agent 生成了什么，以及为什么某次修改没有进入最终视频。

## 典型文件角色

| 文件或目录 | 作用 |
| --- | --- |
| index.html | 根合成与画面内容的入口 |
| 素材目录 | 图片、视频、配音等可访问文件 |
| 合成子目录 | 需要复用或拆分的场景，具体结构依项目而定 |
| 项目配置 | 尺寸、时间或工具所需信息，以当前规范为准 |
| 导出目录 | 最终 MP4、截图等结果，不代替源文件 |

## 时间如何写进画面

合成或媒体通过数据属性描述起点、时长、轨道和尺寸等信息。动画时间轴负责元素如何随时间变化。CSS 层级与轨道时间是不同概念：同一时段显示哪些元素，以及它们如何相互遮挡，都要检查。

## 渲染为什么强调确定性

渲染器在指定时间点捕获画面，再编码为视频。依赖随机数、网络返回顺序、实际播放时间或未加载字体的行为，可能使相同项目得到不同画面。

使用受控输入、稳定媒体路径和可寻址动画；需要随机效果时使用固定种子。检查相同时间点在预览和导出中是否一致。

## 保存一个能够交接的项目

除成片外，保留源码、依赖版本、素材许可与运行命令。引用电脑绝对路径的项目不能直接交给其他机器。本站案例将 GSAP 文件与源码一起提供，详细复现步骤见[案例库](/showcase/)。
