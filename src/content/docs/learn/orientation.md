如果你想做视频，但还分不清 HyperFrames、Studio、Agent 和 CLI，可以先从这里开始。不必一开始就学代码，也不用把每一个工具都装一遍。本栏目帮助你建立产品之间的关系，选出适合自己的第一条路径。

## 先理解你要使用哪种方式

HyperFrames 项目把画面、素材与时间组织起来；桌面应用提供可视工作区，方便对着预览继续修改；CLI 与 Agent 则提供另一种操作项目的方式。官方资料里还会出现浏览器编辑器，不能看到 Studio 这个词就把它与桌面应用当成同一个入口。

如果你希望描述想法、查看结果、再指着画面修改，先走桌面应用路径。已经在 Agent 里工作、希望处理项目文件或自动化操作时，再看相应 Agent 和 CLI 指南。

## 第一次不要同时尝试所有能力

建议先做一个内容很明确的小任务：使用你已经有的标题与图片，形成一段能预览、能修改、能导出的作品。走完一次之后，术语和各个工具才会有实际对应。

应用能安装、Agent 能响应、媒体服务可调用，是不同条件。遇到限制时先确认当前入口与实际提示，不要从“开源”推断所有线上服务都免费，也不要用 CLI 版本代替桌面应用版本。

选定路径后进入 [Studio 创作总览](/learn/studio/)，或从 [CLI 快速开始](/start/cli/) 开始。想先看能做什么，读 [能力地图总览](/learn/capabilities/)。
