这一栏带你在桌面应用里完成一次创作：准备内容，得到初稿，对着画面修改，最后导出检查。你不必把整本知识库读完，先沿一条完整流程做出一个小作品。

## 把第一次创作当成四个决定

先决定要向谁解释什么，再准备必须使用的文字与素材；接着通过分镜确认镜头顺序；有了预览后，定位需要修改的位置；最后选择输出方式并检查实际文件。

例如做一个产品介绍，可以先用已有截图和一句核心说明开始。先让内容顺序成立，再调整标题、配色和节奏。不要在尚未明确要讲什么时，先生成大量新素材。

## 一条可以照着走的路径

| 当前阶段 | 去哪里 | 这一步的完成标志 |
| --- | --- | --- |
| 还不知道各处做什么 | [认识工作区](/studio/workspace/) | 找到对话、预览、素材与时间轴 |
| 准备开始 | [制作第一个视频](/start/studio/) | 得到能观看和继续修改的初稿 |
| 初稿有问题 | [选取、画圈与批量修改](/studio/edit-with-the-agent/) | 修改落在明确对象与时刻上 |
| 准备发出去 | [导出并检查](/studio/export/) | 实际输出文件的画面与声音完整 |

## 已经有内容时从中间进入

有喜欢的参考，读 [参考视频](/studio/reference-video/)，先说明要借鉴什么；经常做同一品牌，读 [品牌资料](/studio/brand-kits/)；已有项目在别的 Agent 中，读 [打开已有项目](/studio/existing-project/)。需要生成一段动态素材时，再看 [视频片段](/studio/video-clips/)。

如果任务没有开始响应，先检查 [Agent 连接](/studio/connect-your-agent/)。应用、Agent 与媒体服务的账号条件不同，先找出阻挡的是哪一层。

## 怎样读这些操作指南

英文按钮名用来帮助你对照界面，不要求你记住整套菜单。界面不同或功能不可用时，记录应用版本、操作系统、当前入口和实际提示。文章基于固定官方资料，未执行的账号与收费步骤会明确说明。想理解操作背后的关系，再进入 [创作机制](/learn/mechanisms/)。
