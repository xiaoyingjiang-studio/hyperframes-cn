能力告诉你“能做什么”，方法帮助你决定“这次先做什么、后做什么”。这一栏把需求、素材、场景、修改与验收连接起来，适合已经有创作目标、希望得到完整结果的人。

不需要先用尽所有工具。一个任务只要选出合适的内容、结构和检查方法，就可以开始。

## 先围绕一个观众问题组织作品

产品介绍要让观众明白产品解决什么问题；知识讲解要让一个概念变得可理解；已有素材剪辑要从真实内容里找到顺序。先确定要留下的认识，再选择画面和声音来支持它。

例如知识讲解可以先写一句核心解释，用一个具体例子展开，再决定哪些关系需要用图形表示。动画应该让这段解释更容易跟上，而不是替代没有想清楚的内容。

## 按你的输入找起点

| 你已经有的东西 | 建议阅读 | 重点观察什么 |
| --- | --- | --- |
| 一个想法与几份素材 | [提示词与修改方法](/guides/prompting/) | 把目标变成能执行的要求 |
| 产品资料与界面 | [产品介绍案例](/showcase/product-intro/) | 信息怎样分成场景 |
| 一个需要讲清的概念 | [中文知识讲解案例](/showcase/chinese-explainer/) | 解释、例子与图形怎样配合 |
| 一组真实数据 | [数据叙事案例](/showcase/data-story/) | 结论与画面证据是否一致 |
| 已有拍摄片段 | [素材剪辑案例](/showcase/footage-edit/) | 取舍、字幕与声音关系 |

这些社区原创案例是框架实践，保留自己的成片与验证记录，不代表 Studio 桌面操作已经实测。参考案例的方法时，应分清入口和素材条件。

## 每一轮只推进一个主要决定

先确认内容与顺序，再看画面层次，最后校对时序、声音和输出。进入下一轮前记下哪些内容已经确认，避免每次都把整个项目重做。遇到方向不明确，可以先要方案或分镜，而不是立即要求生成最终成片。

想直接在应用里做，进入 [Studio 创作](/learn/studio/)；不理解项目怎样保持可编辑，进入 [创作机制](/learn/mechanisms/)；有具体现象无法解决，进入 [问题与限制](/learn/problems/)。
