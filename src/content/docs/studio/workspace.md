Studio 项目将 Agent 对话、画面预览和辅助面板放在一起，时间轴可以在预览下展开。创作时先区分“告诉 Agent 做什么”和“直接操作项目”这两条路径。

## 操作思路

在聊天里，@ 用来加入媒体、项目或样式等上下文，# 选择工具，/ 提供命令与已安装 skills。右侧面板帮助查看媒体、字幕、灵感和图层。先选择具体对象，再补充需要的动作。

## 检查与限制

工具和技能入口会受已连接 Agent、安装内容和账号影响。发送前查看加入的信息是否正确，完成后检查项目画面。菜单中出现某项不代表它无需额外权限或额度。

## 下一步

先完成[第一个视频](/start/studio/)，再了解[准确定位修改](/mechanisms/targeted-edits/)和[预览与导出](/mechanisms/preview-and-export/)。如果界面与说明不同，记录系统、应用版本、使用入口与实际提示，进入[排错指南](/guides/troubleshooting/)。本页只说明公开资料中的使用方法，未在本环境执行账号操作。
