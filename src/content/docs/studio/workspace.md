第一次打开一个项目，可以先把工作区理解成三个互相配合的地方：对话里表达任务，预览里看结果，素材与编辑面板里找到具体内容。不是所有修改都要靠长段文字描述，也不是把文件放进素材列表就已经用进了视频。

先找到这三处，再尝试一个小修改，比逐个记住所有按钮更容易建立方向感。

## 从“我要改这个标题”认识工作区

预览显示当前画面。找到要改的标题后，可以选中它，再把修改要求交给 Agent；也可以画圈或在某个时刻添加评论。这些标注帮助对话指向具体对象。

对话负责说明目标与约束，例如标题改成什么、哪些内容保持不变。预览负责验证结果。素材与图层面板帮助找到文件和元素，时间轴则帮助理解内容何时出现。它们围绕同一项目工作。

## 聊天里的三种选择各做什么

| 入口 | 你在表达什么 | 适合的情况 |
| --- | --- | --- |
| @ 引用 | 这次任务要用哪份文件、素材或参考 | “用这张图作背景” |
| # 工具 | 希望这次任务使用哪类处理方式 | 明确要生成片段或去背景 |
| / 命令与技能 | 使用某项命令或已安装的创作方法 | 选择可用的工作流程 |

这些选择不相互替代。引用一个素材只是告诉 Agent 你指的是哪一个，仍要说它应该怎样用于视频。具体菜单项也会随账号、Agent 与版本不同，页面列出的例子不代表每个环境都完全一样。

## 素材、图层与字幕从哪里理解

Media 显示项目文件，可以把文件加入对话并说明用途；Layers 按画面元素帮助选取；字幕面板与灵感面板分别提供样式和参考。不要把一个面板中的选择，误认为已经完成了制作和验收。

例如选了字幕样式，还要说明应用在哪段内容，并核对实际字幕文本与时间。参考了一段灵感，也要说明借鉴什么，而不是默认照搬全部画面。

## 完成一次最小修改

先观看当前视频，暂停在需要修改的地方，选中一个标题，写出新文字和保留条件。检查待发送列表后提交，等结果出现，再看同一时刻的标题是否正确。随后从头播放，确认相邻内容仍然合理。

想完整走一遍创作，读 [第一个视频](/start/studio/)；想把标注发出去，读 [选取、画圈与批量修改](/studio/edit-with-the-agent/)。本页依据固定官方资料说明界面，没有在当前环境登录应用实操。
