已经在 Claude Code、Codex 或其他 Agent 中建立的 HyperFrames 项目，可以在桌面应用继续处理。官方说明导入不会把项目移动成另一套文件，应用与原工具可能编辑同一目录。

## 操作思路

从应用选择导入或打开项目文件夹，确认看到的是正确项目。支持的命令行交接与会话延续受平台和启动环境影响；官方当前的 Mac 交接路径不能直接推及其他系统。

## 检查与限制

返回外部 Agent 后，先让它了解应用中的修改，再继续工作。保留素材和字体路径，重要修改留好恢复点。项目列表显示过旧名称时，也要检查实际目录和文件内容。

先完成[第一个视频](/start/studio/)，再了解[准确定位修改](/mechanisms/targeted-edits/)和[预览与导出](/mechanisms/preview-and-export/)。如果界面与说明不同，记录系统、应用版本、使用入口与实际提示，进入[排错指南](/guides/troubleshooting/)。本页只说明公开资料中的使用方法，未在本环境执行账号操作。
