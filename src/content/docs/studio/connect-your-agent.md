Studio 提供预览、素材和编辑界面，连接的 Agent 则负责执行创作请求。可以把两者理解为工作台与在工作台上完成任务的助手。选好了 Agent，并不意味着同时获得所有媒体生成服务，账号与费用入口仍需分别确认。

## 第一次请求怎样进入连接流程

尚未连接时发送需求，应用会打开 Connect an agent。选择要用的工具，已安装的可选择 Use，未安装的按 Install 提示操作，再完成它自己的登录。连接后，应用会继续发送最初的请求。

你不必先随意安装所有选项。先确认自己已有的工具和账号，再选一个能够使用的方案。官方列出的 Agent 各有登录与计费方式，不能把应用可下载理解成所有 Agent 调用都免费。

## 三种状态要分别判断

第一是工具是否安装，第二是它能否使用当前账号响应，第三是任务所需的素材服务是否可用。一个只改现有标题的任务，与生成新的声音或视频，对服务的需求可能不同。

如果连接失败，设置中的状态可以帮助区分 Not installed、Not signed in 或 Needs an update 等情况。官方连接面板也会给出失败步骤的操作提示；先处理该步骤，不要反复重发完整视频需求。

## 模型选择与权限怎样影响任务

聊天头部可以选择准备使用的 Agent，设置中还可以调整默认 Agent、模型和工作强度。切换影响后续请求，因此在任务执行前确认当前选择，避免把不同环境的结果混在一起比较。

Auto 与 Full access 的权限范围不同，有些 Agent 可能要求更高的访问方式。阅读应用对当前选择的说明后再决定，不应为了修复所有连接问题直接一律放开权限。凭据放在工具与应用提供的配置位置，不写进项目公开文件。

## 用一个小任务确认连接成立

先选择现有项目中的一处明确变化，例如只替换一行标题。观察对话是否响应、文件与预览是否出现相符变化。这样比直接发起一段长视频更容易判断问题在连接、项目还是媒体服务。

这是一种检查建议，没有在本环境执行 Agent 登录。连接正常后，从 [第一个视频](/start/studio/) 开始；想认识对话、预览与面板怎样配合，读 [工作区](/studio/workspace/)；遇到问题时记录系统、Agent、应用版本和实际提示，进入 [排查指南](/guides/troubleshooting/)。
