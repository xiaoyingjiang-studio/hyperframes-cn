Studio 通过连接的 Agent 执行创作任务。先确认自己选择的工具可以独立运行，再按官方连接页面和应用提示配置；连接成功、账号登录与媒体服务可用是不同的条件。

## 操作思路

打开当前应用中的 Agent 选择入口，核对选择的是预期工具及工作环境。先完成一个小任务，查看对话、项目文件和预览是否发生相符变化，再开展较大的创作。

## 检查与限制

外部 Agent 方案、操作系统和服务授权可能影响体验。不要把连接某个 Agent 理解为同时获得所有素材生成服务；凭据在工具自身的安全配置中管理。
