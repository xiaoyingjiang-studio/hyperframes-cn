如果你知道“想要这种节奏”，却很难用文字描述，可以给 Studio 一段参考视频，再用自己的主题、人物和品牌制作。开始前先想清楚喜欢的是镜头切换、字幕方式还是动画表现，参考越明确，后续越容易判断。

## 选择参考，再确认它属于哪类任务

在首页打开 Reference，可以提供支持的公开视频链接、上传文件，或从参考内容中选择。官方流程会读取视频，再根据内容进入不同方式：人物面对镜头的内容偏向复制剪辑风格，图形动画偏向形成视频创作任务；无法判断时会询问选择。

这一步不是把原片直接作为最终作品。接下来仍要提供自己的内容，并说明哪些部分要替换。

## 把“自己的内容”准备完整

人物内容需要自己的拍摄片段或选择合适的形象方式；图形内容需要说明主题并提供图片、片段等。应用的 What to swap 会列出识别到的替换位置，你可以填写准确文案、上传素材，或按可用条件生成。

例如参考开头是一句提问、结尾是网址，就应分别确认自己的提问和网址。不能因为已上传品牌标志，就默认所有文字身份都已经替换正确。

下面是表达示例，没有实际读取参考：

> 参考这段视频的快速开场和简洁字幕。内容改为我的产品，使用我上传的录屏与标志。保留我写好的开场提问，结尾使用我的网址；原片的人物、音乐和素材不要沿用。

## 用对照帮助下一轮修改

官方界面的 Show original 可以显示参考，完成后还能在同一时钟下并排对照。先看你想借鉴的维度：切换是否合适、字幕是否清楚，再看自己的内容是否自然成立。不是越像原片越好，而是有没有做到这次明确提出的任务。

需要修改时，直接选取、画圈或评论具体位置，进入 [修改流程](/studio/edit-with-the-agent/)。如果想把一个原片逐帧重建成可编辑项目，先读 [参考方式的区别](/mechanisms/references/)。

## 开始前核对权限和素材权利

官方固定来源将 Reference 列为 Pro 相关能力，读取通过 HeyGen 进行，可能由计划或可用的 API 凭据支付。具体可用性以当前账号与界面为准，本页没有执行付费读取。

借鉴剪辑风格不等于获得原片的音乐、镜头、标志和人物使用权。使用自己的素材，或确认已有授权后再使用。
