第一版出来后，先完整看一遍，再决定改什么。Studio 修改的基本方法是：指出位置，说清变化，检查待发送内容，再让 Agent 执行。这样不用把每个视觉细节都翻译成抽象描述。

## 先选择合适的定位方式

要改某个文字或图形，使用预览下的 Select 选中元素，再选择 Prompt to edit 并描述要求。一个区域不好直接选取时，用 Draw 圈出来；只有特定时刻出现的问题，可以用 Comment 标注位置与时间。时间轴范围则适合说明某一段节奏。

例如“把这里变大”，最好补充为“选中的标题在手机上太难读，保留原文和颜色，放大后最多两行”。定位提供对象，文字提供目标，两者合起来才完整。

## 标注完成以后还要发送

选取、绘图与评论不会自己启动制作，它们进入 Pending video edits。查看每一条的说明，可以修改备注或删除不需要的条目；整理好后，用发送按钮把这一批提交。

多条反馈尽量各说一件事。重排整个场景与微调场景内的位置可能相互影响，先决定大的结构，再处理局部细节。组织方法见 [多条修改要求](/mechanisms/batch-edits/)。

## 时间轴上可以直接处理什么

显示时间轴后，可以拖动或裁切片段，也有拆分、删除及针对媒体的快捷编辑。涉及速度、音量和淡入淡出时，先确认操作的是哪段媒体，再观看相邻片段和声音衔接。

直接操作适合明确的小调整；需要整体设计判断时，可以把时间范围连同目标交给 Agent。手动和对话编辑使用同一项目，切换方式以后也应保留已经做好的修改。

## Agent 正在工作时怎样补充

公开资料描述 Enter 和 Ctrl+Enter 在运行中分别用于引导当前运行或排队下一条，行为可在设置中交换。因此看到它还在工作时，先确认自己的发送设置，避免把“下一轮再做”误发成中途改变任务。选取和文件会排队。

## 修改后怎样验收与撤销

先回到标注的位置对照，再完整播放，确认目标做到、保留条件仍满足，声音和字幕没有错位。若整轮修改不合适，聊天运行有 Undo；应用也提供撤销与重做。范围说明见 [保留修改与恢复](/mechanisms/history/)。

确认成片后，进入 [导出与交付检查](/studio/export/)。本页说明官方操作方法，没有在当前环境执行桌面操作。
