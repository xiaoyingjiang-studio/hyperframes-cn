每次修改都应包含位置与动作。选择元素、绘图和评论可以提供上下文，文字说明则定义改动目标。多个标记会进入待处理编辑列表，核对后再统一发送。

## 操作思路

先定位时刻，选中或圈出对象，再写“把什么改成什么、哪些部分保持”。需要处理一个时间范围时，可结合时间轴说明。发送前合并冲突指令，删除已经解决的项。

## 检查与限制

修改后回到相同时刻比较，再播放前后片段。Enter 与 Ctrl+Enter 在 Agent 工作时可能分别引导当前任务或排队，具体由设置控制；不要仅凭按键记忆判断发送结果。
