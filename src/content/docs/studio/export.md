预览满意以后，还差最后一步：把项目渲染成视频文件，并检查真正要发出去的那份文件。导出不是“看过预览”的同义词，文件的尺寸、格式、声音和首尾都需要再确认。

## 先选交付用途，再开导出面板

在项目顶部选择 Export。普通上传与分享通常使用 MP4；如果接收方要求其他格式，再按交付规格选择。画幅、画面尺寸与帧率也应围绕用途决定，不要只因为数值更大就全部调高。

Agent 正在构建项目时，导出可能不可用，先等待本轮运行结束。官方演示中的等待有加速，不能用它估计你的设备耗时。

## 本地和云端有什么实际区别

| 选择 | 工作在哪里完成 | 开始前主要核对什么 |
| --- | --- | --- |
| 本地 | 你的电脑负责渲染 | 本机状态、保存空间与输出设置 |
| 云端 | 项目上传到 HeyGen 后渲染 | 计划或 API 支付入口、项目大小、画幅与帧率限制 |

官方资料列出的云端范围与本地不同，具体限制和权益以当前面板为准。尤其注意：云端任务开始后，Cancel 可能只停止等待，服务器仍可能完成并计费。不要把关闭面板当成已撤销服务调用。

## 设置完成后再开始渲染

检查 Quality、Format 和 Frame rate，并确认 Render on 指向预期位置，再点击渲染按钮。面板可能依次显示准备、绘制、编码、合成与保存，这些阶段说明工作正在进行，不是每次都需要重新发起。

若失败且重试仍无效，先请 Agent 检查项目，再处理导出。若提示已经生成但无法存入 Downloads，应检查磁盘空间和下载目录；这与画面项目本身出错是不同的问题。

## 用输出文件完成最后一次验收

看到 Export ready 后，可以 Open video 播放，或通过显示文件夹的按钮找到 Downloads 中的文件。完整看一次，特别检查开头、结尾、中文换行、声音和切点。若输出与预览不一致，记录设置和具体时刻，交给 Agent 定位。

交付成片的同时保留源项目与素材，后续改标题或重新输出才有基础。解释两种检查方式为什么不同，见 [预览与导出](/mechanisms/preview-and-export/)；不确定问题属于哪一步，回到 [问题排查](/guides/troubleshooting/)。本页没有实际登录应用或执行云端渲染。
