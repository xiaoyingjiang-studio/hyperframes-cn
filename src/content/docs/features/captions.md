字幕既要准确，也要适合观看。先保证文字、时间和语义正确，再考虑动画与装饰。

## 三种文字用途

| 用途 | 重点 |
| --- | --- |
| 信息标题 | 快速说明当前主题，保持稳定的字号与层级 |
| 语音字幕 | 与实际讲话同步，避免逐字识别错误和不合理断句 |
| 动态强调 | 只突出少量关键词，避免每个字都争夺注意力 |

## 一个可靠的制作顺序

已有音频时先获得并核对转写结果，特别检查人名、数字、英文缩写和专业术语。根据说话停顿和中文语义组织句子，再将字幕放到时间轴上。

没有配音的纯文字作品，可以用阅读节奏安排字幕，但需要明确它不是语音自动对齐的结果。

## 提示词示例

> 保留原话含义。字幕采用简体中文，每屏尽量一到两行，按完整短语断句。关键词只强调一个，用浅底深字提高可读性。先列出待确认的人名和数字，再生成。

## 必须检查的画面

查看最长的一句、英文与中文混排的一句、人物或产品下方的字幕以及最后一句。检查手机尺寸下是否可读，背景变化时是否仍有足够对比。

识别与配音能力可能依赖具体本地工具或外部服务，先确认语言、账号和额度。更具体的排版建议见[中文字体与字幕实践](/guides/chinese-typography/)。
