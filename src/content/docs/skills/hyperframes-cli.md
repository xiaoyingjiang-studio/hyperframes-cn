需要创建项目、读时间轴、查看帧、预览、渲染、分享或排查失败时使用。它负责操作路径，不替代影片内容设计。

## 输入与输出

准备项目目录、希望完成的操作及错误输出；结果可能是检查报告、静帧、预览或成片，按任务分别验收。

## 关键规则与影响

CLI 的公开说明按任务组织命令。自动运行需要明确版本，失败时保留错误与修复提示；不要用未实际执行的命令列表充当验证记录。

## 可以怎样表达需求

以下为本站整理的需求示例，不是实际运行记录：

> 检查这个项目的布局与运行问题，查看问题发生的帧；修复后再预览，并告诉我执行范围。

## 职责边界与常见误用

把快速静态检查当成完整验收会遗漏运行与画面问题；仅凭命令成功也不能判断声音和叙事。

## 入口、版本与下一步

本页解释官方正式发布的 Agent skill，不将其自动视为所有 Studio 版本内置的菜单项。技能安装方式和实际发现结果见[Skills 总览](/features/skills-catalog/)，操作中以当前工具显示的名称为准。需要素材时结合 [media-use](/skills/media-use/)，需要完整制作约定时回到 [hyperframes](/skills/hyperframes/)。本页来源固定到 v0.9.94 的仓库提交；账号与服务条件不代表本环境已实测。
