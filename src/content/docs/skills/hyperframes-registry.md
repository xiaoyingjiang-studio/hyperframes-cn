想让标题逐字出现，或者加入一个图表转场，通常不必从零写起。HyperFrames registry 提供可安装的视觉模块；这个 skill 帮助 Agent 先查找合适的模块，再把它接入当前项目并改成你的内容。

关键在“可编辑”：安装下来的内容是项目里的源码，而不只是一个无法拆开的成片。能改哪些部分、怎样接入，仍取决于模块类型和它自身的说明。

## 先分清场景块和组件

Block 可以理解为一段带有自己时间轴的场景，例如完整标题卡或转场。Component 更像场景中的一个零件，例如文字进入效果、光标或纹理。需要一个完整段落时，先找场景块；只想让已有标题动起来，则优先找能放进当前场景的组件。

两者不能仅靠“安装成功”就自动出现在视频里。场景块要挂到主项目上，设置开始时间和持续时间；组件则需要把相应内容和动画接入已有场景。

## 用画面意图寻找模块

比起只说“高级一点”，可以描述画面需要发生什么：数字从旧值变化到新值、卡片展开显示信息、画面冻结后切入下一段。官方目录使用英文索引，所以 Agent 搜索时应将意图转成英文关键词；中文搜不到不能直接判断目录没有这类能力。

先选最接近任务的大单元，再调整文字、配色、字体和持续时间，通常比堆多个效果更容易保持一致。品牌设置需要接到模块的变量上；安装本身不会保证每个模块都自动符合品牌。

## 从找到模块到确认它可用

以“产品数据增长”为例，可以先寻找图表模块，再把数据、标题和品牌颜色换成自己的。随后查看图表关键时刻，确认数值可读、动画完整结束，并且没有挤压同场景里的其他内容。

## 搜索不到时怎样继续

先换成画面行为的描述，并确认搜索使用的索引与类型。官方还提供按语义检索的本地方式，但需要额外下载，不能将其说成默认已经启用。安装需要网络，缓存目录的离线搜索与安装是两件事。

了解完整的 [Skills 与组件目录](/features/skills-catalog/) 后，再按任务选择。缺少真实图片或声音时，应使用 [media-use](/skills/media-use/)，不能把视觉模块当作品牌原始素材的替代品。
