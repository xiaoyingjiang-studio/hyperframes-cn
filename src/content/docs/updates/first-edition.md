这篇是中文站首版的产品梳理，核对日期为 2026 年 11 月 25 日。它不是某个版本的新功能公告。

## 当前最值得先理解的关系

HyperFrames 的使用入口可以从 Studio、编码 Agent 和 CLI 三个角度理解。Studio 把创作与预览放在桌面工作区，Skills 帮助 Agent 按视频规范工作，CLI 则承担明确的项目操作与渲染任务。

## 对新用户的影响

选择入口时不需要先掌握全部工具。创作者从 Studio 开始，已有编码工作流的用户从熟悉的 Agent 开始，开发者可以用 CLI 理解最小循环。

无论哪条路径，第一次都建议做短片、少依赖、明确中文文案。先确认生成、预览、修改和导出四步都能完成，再增加配音、生成素材和复杂效果。

## 对已有用户的提醒

分别记录 CLI、Skills 和项目版本。更新其中一个之后，先在小项目中检查兼容性，再处理重要作品。官网产品入口、账号方案与开源本地工具的条件也需要分别核对。
