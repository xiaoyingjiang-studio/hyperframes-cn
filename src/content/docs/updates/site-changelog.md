本页记录中文站自身变化，与 HyperFrames 官方版本更新分别维护。

## 2026-11-25 · 首版工程

- 建立产品介绍、快速开始、能力、指南、案例、更新和贡献七个内容栏目。
- 提供 32 个首版页面及来源映射；对账号实操与本地案例验证分别注明边界。
- 建立四个可下载的原创 HTML 视频项目，渲染结果与执行记录随项目提供。
- 接入中文本地搜索、RSS、站点地图和机器可读内容索引。
- 增加上游检测、外部 AI 候选稿、人工审核及 Cloudflare 发布工作流。

## 发布状态如何确认

本页表示仓库内容变化，不代表已经完成外部账号配置或正式部署。线上版本以部署工作流结果和对应 Git 提交为准；案例渲染以 verification.json 的记录为准。

## 后续维护约定

修正文字时说明修正范围；变更命令、适用版本或功能条件时重新核对来源。普通排版调整不会自动刷新页面的核对日期。

发现问题可以提交 Issue，并附页面地址、预期内容和证据。参与方式见[贡献指南](/community/contributing/)。
