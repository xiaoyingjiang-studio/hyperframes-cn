## 如何阅读更新

先看变化涉及哪个使用入口，再确认当前安装版本或账号是否已具备对应能力。官方 main 分支中的文档变化，不自动等于稳定版已经发布。

涉及命令、价格、系统要求、服务可用性的变化，会在审核时单独核实。尚未完成中文转化时，相关页面保留原核对日期，并在检测到变化后显示待核对提示。
